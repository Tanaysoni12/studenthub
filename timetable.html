Data Structures

Arrays, linked lists, stacks, queues, trees, graphs, and algorithm analysis.

Database Management Systems

Relational databases, SQL, normalization, transactions, and database design.

Object-Oriented Programming

Classes, objects, inheritance, polymorphism, exception handling, and Java programming.

Computer Organization

Digital logic, processors, memory systems, instruction sets, and computer architecture.

Discrete Mathematics

Logic, sets, relations, combinatorics, graph theory, and mathematical reasoning.
